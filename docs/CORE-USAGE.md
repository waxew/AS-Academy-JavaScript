# استفاده JavaScript از AS Academy Core

این ریپو Course Repository است و نباید کد عمومی Android را کپی کند.

## از Core دریافت می‌شود
- App Shell و Navigation
- Design System و RTL
- Room و Migrationها
- Lesson Renderer
- Progress
- Quiz Engine
- Exercise Engine
- Project Engine
- Search / FTS
- Bookmark / Notes
- Profile / Drawer / Settings
- Backup / Restore
- Content Update / Validation
- CodeRunner Plugin API
- CI rules و قراردادهای نسخه‌بندی

## در این ریپو باقی می‌ماند
- محتوای JavaScript
- مثال‌های JavaScript
- تمرین‌ها و آزمون‌های JavaScript
- پروژه‌ها و Glossary
- Branding و Assetهای JavaScript
- تنظیمات JavaScriptRunner

هر قابلیت عمومی جدید ابتدا باید در `AS-Academy-Core` پیاده‌سازی شود و سپس این پروژه آن را مصرف کند.
